API Testing — RESTful Booker
About the Project

This project demonstrates manual API testing using Postman and the RESTful Booker public demo API.

The collection covers the main CRUD operations for booking management, authentication, response validation, and verification of changes.

Test Scenarios
Authentication
Send an authentication request.
Extract and store the authentication token for subsequent requests.
Booking CRUD
Create: Create a booking and store its ID in a collection variable.
Read: Retrieve a booking and validate the response.
Update: Update booking details and verify the changes.
Delete: Delete a booking and verify that it is no longer available.
